# Stratosphere
Stratosphere is a real-time trend detection system using Bluesky

* NATS JetStream to process the Bluesky firehose
* Named Entitiy Recogniction built with spaCy and FastAPI
* ClickHouse for data storage and trend queries
* LLM integration for trend summarization and validation
* Python
